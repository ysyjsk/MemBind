# Native Platform and Adapter Decision

Status: `FROZEN_FOR_L0` (the context-length branch remains pending the deterministic L0 budget calculation).

The formal arms share Graphiti `0.29.3` at commit `021d3a57d511f21b10adaf7fa923bd5c1fce5e9d`, including the upstream `Graphiti.add_episode` call graph, `OpenAIGenericClient`, prompts, Pydantic response models, extraction, resolution, deduplication, and database mutation behavior. The edge extraction call site is retained at the upstream `max_tokens=16384`. The implementation may add only a transparent transport facade for endpoint routing, telemetry, official sampling fields, and a stable logical-request seed.

The shared input is `MAB_ROLE_AWARE_LOSSLESS_8192_V1`: each canonical role-marked MAB session is partitioned into contiguous, non-overlapping chunks of at most 8192 characters. Turn boundaries are preferred, and long turns use whitespace or Unicode-safe code-point boundaries. Chunk identity is metadata in the immutable manifest, never text inserted into the model body. Per-session chunks form an explicit predecessor chain; sessions remain ordered by source sequence. Concatenation is checked byte-for-byte after UTF-8 encoding.

P0 is Qwen3-8B-AWQ on two identical single-GPU RTX 3090 Ti replicas (`tensor_parallel_size=1`) with `enable_thinking=false`, `temperature=0.7`, `top_p=0.8`, `top_k=20`, `min_p=0`, `presence_penalty=1.5`, JSON schema output through xgrammar, and SDK retries disabled. A stable seed is derived from the logical dataset/context/session/chunk/prompt/message identity, so A/B/C receive the same seed for the same request. P1 is only a compatibility fallback after a reproducible P0 structured-output failure and is never selected by speed or QA.

The context-length choice is made once by L0 using the real Qwen tokenizer over the complete five-context manifest and the upstream call-site output budgets. If every request plus a 256-token safety margin fits 40960, the platform uses `max_model_len=40960` with YaRN disabled. Otherwise it uses `max_model_len=65536` with the official static YaRN settings `factor=2.0` and `original_max_position_embeddings=32768`. Existing services using YaRN `factor=1.6` and `original_max_position_embeddings=40960` are historical and cannot supply the new formal platform identity.

The source set is intentionally an intersection of public evidence: Graphiti supplies the native algorithm and call boundaries; Qwen documentation and generation configuration supply deployment and decoding settings; AutoSchemaKG supplies the 8192-character full-chunk extraction precedent; MemoryAgentBench supplies the official dataset authority. No source is treated as evidence for a result it did not measure. The official Zep `content[:9998]` behavior and the previous finite-pair runtime are retained only as separate references or invalid historical qualification, never as the formal Native arm.
