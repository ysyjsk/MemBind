| prior line | inherited premise | V7 boundary |
|---|---|---|
| SAC / Adapton / Nominal Adapton | change propagation, memoization, stable names, FSC | semantic dependency closure and native seam contract are system-specific |
| Differential Dataflow / DBSP | delta and incremental view maintenance | d=1 operator-scoped completeness; no multi-delta claim |
| Continuous Top-k | influence region and cutoff reasoning | consumer-visible ties, exact backend contract and adaptive demand |
| Aria / Spectrum | snapshot/OCC/ordered execution | state-dependent agent memory and native continuation |
| Parrot / Agentix | agent dataflow and scheduling | no speculative scheduler claim |

| MemTX / MemTxn / Continuity Kernel | transactional or continuity framing | M2 persistence is conditional and separate from M1 |

V7 does not claim to invent any inherited mechanism. A positive M1 claim is
limited to the composition of a sound semantic-read certificate, complete
adaptive demand lineage and a proved native-continuation refinement.
